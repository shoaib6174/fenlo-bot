## GIG FAQ (up to 10)

### Q1: What is a RAG chatbot and how is it different from ChatGPT?
```
RAG (Retrieval-Augmented Generation) means the chatbot only answers from YOUR documents — not from the internet. Every answer includes citations showing which document it came from. Unlike ChatGPT, it won't hallucinate or make up information. It only knows what you teach it.
```

### Q2: Can I try it before ordering?
```
Yes! Visit rag.fenloai.com to try the live demo. You can chat with the bot, view the analytics dashboard, browse conversations, and see the knowledge base — all live and interactive.
```

### Q3: What file formats do you support?
```
PDF, Word documents (.docx), and plain text files. I handle all the parsing, chunking, and embedding. Just send me your files and I'll take care of the rest.
```

### Q4: Do I get the source code?
```
Yes, every package includes full source code (frontend + backend). You own everything. No monthly fees, no vendor lock-in. You can modify, extend, and host it wherever you want.
```

### Q5: What channels can the chatbot be deployed to?
```
Website widget (floating chat bubble), WhatsApp Business, Telegram bot, and REST API for custom integrations. The Basic package includes the website widget. Standard adds one more channel. Premium includes all channels.
```

### Q6: How does the analytics dashboard work?
```
The dashboard shows conversation volume over time, sentiment analysis (positive/negative/neutral), quality scores, top questions asked, and lead scoring. Available in Standard and Premium packages. You can see a live demo at rag.fenloai.com/analytics.
```

### Q7: Can I update the knowledge base after delivery?
```
Absolutely. The admin dashboard lets you upload new documents, delete old ones, and monitor knowledge gaps (questions the bot couldn't answer). The system automatically re-indexes when you add new content.
```

### Q8: What tech stack is this built with?
```
Backend: FastAPI (Python 3.12) with PostgreSQL and Redis. Frontend: Next.js 15 with React 19. Vector search: Pinecone. LLM: Groq (primary) with OpenAI failover. Everything is containerized and deployment-ready.
```

### Q9: Do you provide hosting/deployment?
```
The Premium package includes full AWS deployment with CI/CD. For Basic and Standard, I deliver the source code with a deployment guide, and you can deploy on your own server, AWS, or any cloud provider. I can help with deployment setup as an add-on.
```

### Q10: How long does it take?
```
Basic: 7 days. Standard: 10 days. Premium: 14 days. Complex projects with 100+ documents may need more time — message me first and I'll give you an accurate timeline.
```
